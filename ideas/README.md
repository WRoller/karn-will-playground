## How to Use This Document

- Add new ideas as rows in the table above.
- Keep descriptions to 1-2 sentences — enough to jog memory and spark conversation.
- Link to a dedicated research doc in this folder for anything that goes deeper.
- Owner = whoever is driving the thinking forward (not necessarily sole contributor).
- Use Cursor skills in `.cursor/skills/venture-*` per phase (see playbook).
