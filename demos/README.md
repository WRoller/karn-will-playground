# Demos

Throwaway prototypes that test one hypothesis from a [prototype brief](../ideas/templates/prototype-brief.md).

## Rules

- One folder per idea slug: `demos/<slug>/`
- Each demo must have a `README.md` with: how to run, demo script, what we learned
- No production concerns (auth hardening, billing, scale) unless the hypothesis requires it
- Prefer deleting over maintaining — copy learnings back to `ideas/*-research.md`
